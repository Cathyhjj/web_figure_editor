Figure Editor panel layout checks

Exercises docked and floating panel resizing, cancellation, persistence, reset, and responsive layouts in the actual editor. These checks only change panel layout; they do not import files or edit the project.

Run on http://127.0.0.1:18768/tests/windows.html with python3 -m http.server 18768 --bind 127.0.0.1. The test saves and restores only this separate origin’s panel layout preference.
