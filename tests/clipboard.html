Figure Editor Clipboard checks

Run Clipboard checks uses generated PNGs and synthetic clipboard events and decodes image output for other apps. Downloads stay in memory and this suite does not change the system clipboard. The separate Copy test selection button intentionally writes the generated selection to the system clipboard for manual paste verification.

Run on http://127.0.0.1:18766/tests/clipboard.html with python3 -m http.server 18766 --bind 127.0.0.1. Running replaces only the test-origin draft, separate from the normal editor draft on port 8766.
