Figure Editor folder checks

Exercises the actual editor with generated PNG files, nested directories, and mocked read-only folder pickers. Tests import previews, placement, undo/redo, source lists, and Save/Open without downloading files or opening native dialogs.

Run this page on http://127.0.0.1:18766/tests/folders.html using a separate local server: python3 -m http.server 18766 --bind 127.0.0.1. The test draft stays on port 18766, separate from the normal editor draft on port 8766. Running replaces the test-origin draft.
