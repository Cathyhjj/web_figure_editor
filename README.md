# Figure Editor

本地论文组图编辑器：拖入图片，像在 PPT 中一样移动、缩放、添加文字，再保存项目或导出论文图。应用使用原生 HTML、CSS 和 JavaScript，无须安装 npm 依赖，不使用云端服务或上传素材。

## 启动

**桌面图标（macOS）：**运行一次 `python3 scripts/create_desktop_app.py`，会在桌面创建 **Figure Editor.app**，图标沿用编辑器的三色面板标志。双击即可后台启动服务并打开 Chrome（未安装时使用默认浏览器），无需保留终端窗口。

桌面应用绑定创建时的这个仓库文件夹，直接读取当前文件，包括最新本地 commit 和未提交修改；不复制应用源码，也不自动拉取远程仓库。源码更新后再次双击，会验证运行版本，必要时重启它管理的服务。仍使用 `http://127.0.0.1:8766/`，保留同一浏览器的草稿和布局。日志位于仓库的 `.desktop-runtime/`。如果该端口被旧的手动服务占用，请先在原终端按 `Ctrl + C`；其他程序不会被自动停止。移动仓库后需重新创建桌面图标。

**macOS：双击 [start.command](start.command)**，自动启动本地服务并打开浏览器（需要 Python 3）。已有服务的页面、脚本与本应用一致且支持本地文件定位时会直接复用；若端口被旧的静态服务或其他服务占用，则提示冲突并退出，不会停止其他服务。

也可以在本仓库根目录运行：

```sh
python3 server.py
```

打开 <http://127.0.0.1:8766/>。启动新服务后请保留终端窗口，在终端按 `Ctrl + C` 停止服务。请通过这个本地地址访问，不要直接双击 `index.html`。

推荐使用 Chrome 或 Edge，以便在浏览器支持时关联本地文件。其他浏览器可使用素材副本；具体能力以浏览器提供的权限接口为准。

也可用 `npm start` 启动。升级前若使用 `python3 -m http.server`，请先在旧服务的终端按 `Ctrl + C`，再通过新的启动方式运行并刷新页面，才能使用 **Locate**。

## 基本流程

1. 点击 **Add images / MP4**，或将 PNG、JPG、WebP、SVG、MP4 文件拖入画布。
2. 点击对象后拖动位置，拖动右下角调整大小；图片默认保持比例，按住 `Shift` 拖动可自由缩放。拖动图片左右边的中点只改变宽度，拖动上下边的中点只改变高度；旋转后的图片沿自身方向拉伸，对边保持固定。在 **Object properties** 面板输入精确位置、尺寸、旋转及透明度。
3. 使用 **Text** 添加标注；选中文字后，用顶部 **Font** 选择或输入本机字体名称，调整字号（px），或点击 **A⌃ / A⌄** 放大、缩小。支持多选文字统一修改，锁定对象会跳过，可用 Undo 撤销。双击文字，在 **Object properties** 中编辑内容、字体、字号、颜色和对齐。换行请按 `Enter`。字体需要安装在本机，未安装时浏览器会使用替代字体。
4. 在画布或周围空白处按住鼠标拉框，选中完全框住的图片、文字和形状；向任意方向拖动均可，隐藏和锁定对象会跳过。按住 `Shift` 拉框可追加选择，`Shift + 点击` 可逐个增减选择。拖动任一选中对象即可整体移动，保持相对位置，一次 **Undo** 撤销整组移动。点击空白取消选择，拉框时按 `Esc` 放弃本次框选。也可使用 **Align** 工具；**Distribute horizontally** 将至少三个对象水平等距排列。在 **Layers** 中选择、隐藏或锁定对象。
5. 点击 **Save** 保存包含全部 slides 的 `.figure.json`：新项目首次选择位置，**Open** 打开的项目直接保存回原文件；**Save As…** 另选位置保存副本。点击 **Export** 可将当前 slide 导出为 PNG、SVG 或 PDF，或选择 **PPT** 导出可编辑 PowerPoint，选择 **HTML report** 导出全部 slides 的离线报告。

画布和字号的单位为 CSS px，按 **96 px / inch** 计算物理尺寸。预设为约 85 × 64 mm 单栏、180 × 120 mm 双栏和 120 × 120 mm 方形，整数像素会带来少量尺寸舍入。画布缩放只改变屏幕显示。

选中图片后，在 **Object properties → Shadow** 勾选开关即可添加阴影。可以选择柔和、右下、下方或硬边预设，也可以用滑块或数值框调整颜色、透明度、大小、模糊、角度和距离。模糊与距离使用与 PPT 相同的 **pt** 单位，角度 `0°` 向右、`90°` 向下。默认效果为黑色、60% 透明、100% 大小、5 pt 模糊、0 pt 距离的居中柔和阴影；透明图片按实际轮廓投影。取消开关或选择 **No shadow** 可移除效果并保留参数。支持撤销、重做，锁定图片时无法调整。

阴影随项目、自动草稿、复制和副本保存；PNG、SVG、PDF、HTML 报告和复制为图片均保留效果，PPT 导出保留为可继续调整的原生阴影。不同渲染器的模糊边缘和半透明图片叠加效果可能略有差异。与其他内容一样，整页导出会裁掉画布外的部分。

## 多页组图与面板

每个项目可包含 **1–100 个 slides**。在左侧 **Slides** 点击缩略图切换页面，用画布上方的 **Slide name** 重命名。

- **New slide**：在当前页后插入空白页，沿用当前画布尺寸和背景。
- **多选**：按住 **⌘ / Ctrl** 点击缩略图可添加或取消选择，**Shift + 点击** 选择连续区间，**⌘ / Ctrl + Shift + 点击** 将区间加入已有选择。在 Slides 面板按 **⌘ / Ctrl + A** 全选；普通点击恢复单选。选中的缩略图高亮，当前画布对应页边框更深。
- **Duplicate slide**：为所选的一张或多张 slide 生成副本，复制后的对象可独立编辑。
- **Copy / Paste**：复制所有选中 slides，再按原项目顺序一次插入当前页之后；也可用 **⌘ / Ctrl + C、V**。可跨项目粘贴，保留每页名称、尺寸、背景、原图、图层顺序及隐藏/锁定状态。空白页同样支持，共享素材只保留一份；一次撤销/重做处理整批 slides。
- **Delete slide**：删除选中 slides，可用 **Undo** 恢复；至少保留一页，全选时删除按钮禁用。在 Slides 面板按 **⌘ / Ctrl + D** 生成副本，按 **Delete / Backspace** 删除选中页。

**Slides、Assets、Layers、Canvas settings、Object properties** 是五个独立面板。拖动面板标题栏即可将它浮起并移动，也可点击 **Float**；浮动后拖动右下角调整面板大小。停靠时，拖动 Slides 的右边缘、Assets 的左边缘或右侧属性栏的左边缘调整栏宽；拖动 Layers、Canvas settings、Object properties 的底边调整各面板高度，内容较多时可在面板内滚动。窄屏下各栏自动堆叠，可调整面板高度。点击面板标题栏的 **Dock** 可将它放回原来的停靠位置并恢复停靠尺寸，点击 **Reset layout** 可恢复全部面板的默认位置和尺寸。用 Tab 聚焦尺寸手柄后，方向键可调整 10 px，按住 Shift 可微调 1 px；拖动时按 Esc 取消。

面板的位置、大小和浮动状态会保存在当前浏览器中，刷新或重新打开同一本地地址时恢复；此布局不包含在 `.figure.json` 中。清理浏览器数据会清除保存的布局。面板布局只影响操作界面，不改变画布对象或导出内容。

**Assets** 是整个项目共用的素材库，可通过 **Place** 或拖动缩略图将素材放到当前页；**Layers** 只显示当前页的对象。每页的对象位置、文字、样式和画布设置独立；同一素材的 **Link** 或 **Refresh** 更新会反映在所有使用它的页面。

在 **Assets → Add folders** 选择本地文件夹，会递归导入其中及全部子文件夹里的 PNG、JPG、WebP、SVG 图片；也可直接把文件夹拖到 Assets 面板。可重复添加多个文件夹。素材按原目录层级显示，点击文件夹名称可折叠或展开，每层显示包含的图片数；展开后可看缩略图，再点击预览、**Place** 或拖到画布。文件夹导入只添加素材，不会自动铺到画布上。无支持图片的空目录不会显示，其他类型文件会跳过，损坏或超限的图片会显示错误。

目录路径随项目、自动草稿和来源清单保存，同名图片在不同子目录中分别保留。浏览器支持时会关联原图；否则使用内嵌副本。文件夹导入是当次快照，不自动监控之后新增的文件。仍适用单图 25 MB、每次 100 MB / 6400 万解码像素和每项目 500 个素材的限制。

## 保存与本地文件关联

**Save** 保存的 `.figure.json` 包含全部 slides、当前页、对象、样式和一份共享的内嵌素材库，可以搬到另一台电脑重新打开。文件名、原始尺寸、格式、关联状态等来源信息保留在项目中；**Download source list** 下载整个项目的 `.sources.json`，包含跨页素材使用记录。

- **Save / ⌘或Ctrl+S**：通过 **Open** 选择的已有项目保存回原文件。新项目首次保存时选择文件名和位置，以后的 Save 使用同一文件；修改项目名称不会自动更换文件。
- **Save As… / ⌘或Ctrl+Shift+S**：每次选择新的保存位置，成功后后续 Save 使用新文件。取消或保存失败会保留原保存目标和当前修改。
- 支持直接文件访问的浏览器（如 Chrome、Edge）会在需要时请求写入权限。保存目标和草稿一起保留在当前浏览器中，刷新后可继续 Save；如果浏览器不能保留文件访问，Save 按钮提示该关联仅限本次会话。拒绝授权或写入失败时会显示错误，可重试 Save 或选择 Save As。
- 不支持文件选择与写入接口的浏览器仍可 Open，但 Save 和 Save As 只能下载副本，页面会明确提示，无法直接覆盖原文件。升级前已打开的草稿也没有原文件访问权限：首次 Save 需选择原文件位置，之后即可直接保存。

**Open** 兼容旧版单页 v1 项目：打开时将原有画布和对象迁移为第一页，保留素材与来源信息；下次 **Save** 将所选文件更新为多页 v2 格式。若要保留旧版文件，请使用 **Save As…** 保存到另一文件。

只有在你选择文件、浏览器支持文件句柄且授予读取权限时，应用才能关联本地原图。句柄保存在当前浏览器的本地存储中，不能随 JSON 项目转移；重启浏览器、切换浏览器或撤销权限后，可能需要重新授权。素材卡片中的 **Refresh** 会重新读取已授权文件；**Link** 可重新选择来源。不支持句柄时，**Link** 通过文件选择更新素材副本。

**Locate** 直接在 macOS Finder 中显示并选中素材的源图片，不再弹出选择原图窗口。优先使用本机已记录的位置或内容匹配的仓库路径；外部图片通过 Spotlight 在用户目录中按完整文件名及已有子目录路径查找。只有一个候选时直接显示当前源文件，即使它在导入后被修改、没有旧指纹或只是云端占位文件；不会因此更新项目中的图片副本或排版。多个候选时，在有限读取范围内用内容指纹尝试区分，无法唯一确定则显示提示，不猜测文件，也不弹出文件选择器。未找到时会提示文件可能移动、删除或尚未被 Spotlight 索引。自动识别的位置保存在本地忽略文件 `.local-locations.json` 中，不包含在项目导出中。 Locate 不更新 Link 关联；通过 Spotlight 查找外部图片时，不会为了内容校验下载云端占位文件。该功能需要通过 `start.command`、`npm start` 或 `python3 server.py` 启动本地服务；普通静态服务器仍能编辑和导出，但不支持 Finder 定位。

网页不能永久、无权限地读取任意本地路径。关联不可用时仍可使用项目中的副本，编辑和导出不会修改原图。浏览器会自动保存一份包含全部 slides 的当前草稿，但 **New project** 或 **Open** 会替换它；请定期使用 Save 保存项目文件，清理浏览器数据可能删除草稿和句柄。自动草稿不会写入项目原文件；只有明确执行 Save 或 Save As 才会写入。

## 导出

点击 **Export**，选择 **File format** 后点击 **Export file**。PNG、SVG 和 PDF 导出当前页，对话框会显示页名；**PPT** 和 **HTML report** 导出项目中的全部 slides，并显示总页数。要保留后续编辑能力，请使用 **Save** 保存项目。

| 格式 | 输出内容 |
| --- | --- |
| PNG | 整张图栅格化；可选 150、300、600 DPI，同时调整输出像素尺寸并写入对应分辨率元数据。 |
| SVG | 编辑器中的文本、矩形和线条保留为矢量，图片以栅格数据内嵌；字体不嵌入，接收方需要安装相同字体。 |
| PDF | 与画布物理尺寸一致的单页文档。文字转为矢量轮廓（不可搜索或作为文字编辑），矩形和线条保留矢量；图片保留源像素，带阴影的图片按所选 150、300、600 DPI 单独栅格化。保留透明度，接收方无须安装相同字体。 |
| PPT (.pptx) | 按项目顺序导出全部 slides；文字、矩形、线条为 PowerPoint 原生可编辑对象，图片为可独立移动和缩放的内嵌图片。保留图层顺序、旋转和透明度，不导出隐藏对象。字体不嵌入。 |
| HTML report | 按项目顺序包含全部 slides、页名和目录的单个 `.html` 文件；图像和样式均已内嵌，可离线打开。文本和编辑器形状保留为矢量 SVG，图片为内嵌栅格，字体不嵌入。报告为只读，不能代替可编辑项目。 |

PNG 的栅格图宽度为 `画布宽度 × DPI / 96`，高度同理。PDF 页面按 `96 CSS px = 1 inch = 72 pt` 保留画布物理尺寸；**PDF shadow resolution** 只影响带阴影图片的局部栅格化分辨率，不改变矢量文字、形状或其他图片的像素数。提高 DPI 不会补出原始图片中没有的细节；图片属性显示其当前排版下的有效分辨率。过大的阴影图像会被拒绝，请减小图片尺寸或阴影分辨率。

PDF 的文字轮廓通过本地 macOS 服务和系统 CoreText/CoreGraphics 字体框架生成，需要 macOS 与 Swift 命令行工具（Xcode Command Line Tools）。请使用 `start.command`、`npm start` 或 `python3 server.py` 启动，更新后重启旧服务。使用本机安装的字体和系统字体回退，希腊字母、中文等随字体轮廓写入 PDF。普通静态服务器、不支持的系统或文字轮廓服务不可用时，会显示导出错误，不会自动把整页转成位图。只含形状和图片、没有编辑器文字对象的页面无需文字轮廓服务；导出过程不会将项目或字体发送到远程服务。

导入的 SVG 会栅格化用于显示和导出，同时在项目中保留原始 SVG 数据。SVG 文件内原有的路径和文字不会成为独立可编辑对象。

PPT 导出在浏览器中本地完成，无须安装 PowerPoint 或联网。所有页面使用第一页的尺寸；尺寸不同的页面会等比缩放、居中，空白区域为白色。超出 PowerPoint 1–56 英寸范围的第一页会连同内容等比缩放到支持的范围，极端长宽比会提示错误。导出窗口会显示实际尺寸和缩放说明。编辑器中文字按原有换行保留；接收方需安装相同字体，否则排版可能变化。图片内部的曲线、坐标轴和文字仍是图片内容，导入 SVG 也使用已有栅格副本；WebP 在导出时转成 PNG。若要回到本编辑器继续编辑，请保留 `.figure.json`。

HTML 报告下载后可以直接在浏览器中打开，无须启动编辑器或联网；它不加载外部图像、字体或脚本。用目录跳转到各页，使用浏览器的 **Print** 打印，或在浏览器支持时保存为 PDF。打印版会调整页面排版和缩放，浏览器也可能将部分内容栅格化；需要确定的论文图尺寸或 DPI 时，请使用单页 SVG、PNG 或专用 PDF 导出。继续排版和编辑请保留 `.figure.json`。

## MP4 视频

使用 **Add images / MP4**、拖放或 **Add folders** 导入 MP4。单文件上限 25 MB，每次导入上限 100 MB；视频原始字节与封面一起保存在 `.figure.json`，重新打开不依赖原始文件路径。建议使用 H.264 视频与 AAC 音频；不重新编码，无法在当前浏览器解码或没有视频画面的文件会提示错误。

画布和页面缩略图显示视频第一帧及播放标识。在 Assets 点击 **Preview**，或选中视频后在属性面板点击 **Preview video**，可播放、暂停、拖动进度。视频可移动、缩放、旋转、隐藏、复制和跨页粘贴；暂不提供视频裁切、剪辑或阴影。

选择 **Export → PPT** 后，原始 MP4 与封面嵌入 `.pptx`，无需随 PPT 另带视频文件。在桌面 PowerPoint 的幻灯片放映中点击视频播放。隐藏或未放置的视频不会进入 PPT，重复放置同一视频只嵌入一份原始文件。播放兼容性取决于 PowerPoint 和系统支持的编码。

PNG、SVG、PDF、HTML 报告及复制为图片使用封面帧；这些静态输出不包含可播放视频。

## 图片裁切

选中一张图片，在 **Object properties** 点击 **Crop**（已裁切时为 **Edit crop**）。在完整原图预览上拖动四边、四角调整范围，拖动框内移动选区，然后点击 **Apply crop**。**Cancel** 或 `Esc` 放弃本次调整；**Full image** 将预览选区恢复为完整图片，仍需点击 Apply。

点击 **Restore original** 可恢复完整图片；裁切和恢复都支持撤销/重做。原图字节保存在共享素材中，每个图片对象有独立裁切范围；重复裁切、复制对象或页面、保存再打开均保留范围。裁切不会改变源图片的显示比例、旋转或原有位置；恢复时会沿当前图片的缩放和旋转展开。锁定图片需先解锁。

PNG、SVG、PDF、HTML 报告、页面缩略图和跨应用复制均显示裁切后的区域。PPT 导出使用原生可编辑裁切并保留完整嵌入图片。SVG、HTML、PPT 和项目文件仍包含完整源图，裁切只控制可见范围。刷新或重新链接素材后，沿用原有的相对裁切范围。

## 快捷键

`⌘` 用于 macOS，其他系统使用 `Ctrl`。除保存外，下列快捷键在未编辑输入框时生效。

| 操作 | 快捷键 |
| --- | --- |
| 保存项目 | `⌘ / Ctrl + S` |
| 另存项目 | `⌘ / Ctrl + Shift + S` |
| 撤销 / 重做 | `⌘ / Ctrl + Z` / `⌘ / Ctrl + Shift + Z`；也可 `Ctrl + Y` |
| 复制所选 / 粘贴 | `⌘ / Ctrl + C` / `⌘ / Ctrl + V` |
| 复制 / 粘贴所选 slides（先点击缩略图） | `⌘ / Ctrl + C` / `⌘ / Ctrl + V` |
| 全选 slides（焦点在 Slides 面板时） | `⌘ / Ctrl + A` |
| 剪切所选 | `⌘ / Ctrl + X` |
| 直接生成副本 / 全选可见对象 | `⌘ / Ctrl + D` / `⌘ / Ctrl + A` |
| 删除所选 / 取消选择 | `Delete` 或 `Backspace` / `Esc` |
| 移动 1 px / 10 px | 方向键 / `Shift + 方向键` |

先点击画布上的图片、文字或形状，再用 **Cmd+C → Cmd+V** 复制粘贴；支持多选、跨 slide，以及在编辑器项目之间粘贴。副本保留尺寸、样式、图层顺序和图片副本，可独立移动与编辑；每次粘贴略微偏移，支持撤销/重做。复制的对象数据通过系统剪贴板传递，后续复制外部内容会替换它。

使用 **Cmd+X → Cmd+V** 可剪切并移动所选对象，也可粘贴到支持图片的其他应用。剪贴板写入成功后才移除原对象，一次撤销可恢复；写入失败或等待期间原对象发生变化时保留原对象。锁定对象不会被剪切。在文字输入框内，Cmd+X 仍剪切选中的文字。

从截图工具或其他应用复制的 PNG、JPG、WebP、SVG 图片，也可点击画布后直接 **Cmd+V** 导入；来源应用需要向剪贴板提供图片数据，仅有文件路径或网页链接时请使用 **Add local images**。在文字输入框内，复制粘贴仍编辑文本。

浏览器支持系统图片剪贴板时，**Cmd+C** 同时复制透明背景 PNG，随后可在 PowerPoint、微信等支持图片粘贴的应用中按 **Cmd+V**。多选对象会合成为一张图片，保留排版、旋转和透明度；粘回本编辑器仍保持各对象可编辑。PNG 和可编辑对象共同写入成功后，底部显示 **Copied**，再进行粘贴；若写入失败，会显示 **Copy failed**，此时不能认为对象已经复制，可重试或使用 **Export**。不支持系统图片写入的旧浏览器仅复制编辑器对象，并会明确提示。复制图片会按原图分辨率和文字清晰度生成，并受输出像素上限保护；图片内部文字和曲线仍是图片内容。

## 示例与本地素材

**Load example** 优先打开本机可选的 `examples/local-demo.figure.json`。没有该文件时，应用使用代码生成的合成示例；新克隆的仓库可以直接运行，无须论文或外部素材。

本地的 `examples/`、`evidence/`、`chat_history.md`、`.local-backups/` 和用户保存的图稿不纳入 Git。已有的论文示例、PPTX、原始图片、派生图片、来源清单与报告保留在本机。通过 **Open** 可以直接打开保存在其他位置的 `.figure.json`，无须复制到仓库。

### 从 PowerPoint 导入一页

点击顶部 **Import PPTX**，选择 `.pptx` 文件，然后在 **Choose a slide** 中选择页码。窗口显示转换后的预览、独立对象数量和 **Import notes**；点击 **Insert as new slide**，在当前页之后插入该页，自动切换到新页。一次 Undo 可撤销整页导入，Redo 可恢复；导入不会替换现有页面或改写原 PPTX。

图片与文字分别可编辑，保留画布尺寸、对象位置、尺寸、旋转、图层顺序及常见主题/母版样式。PNG、JPEG、WebP 图片保留源数据，普通裁剪保留完整原图，可用 **Restore original** 恢复。SVG 会沿用图片导入器生成栅格显示副本并保留原始 SVG。分组展开为独立对象；文本按本机字体测量换行，混合样式、特殊行距可能拆成多个可编辑文字对象。编辑后的内容随 `.figure.json`、保存/重开及现有导出一起保留。

这是支持常见科研排图元素的导入器，不是完整 PowerPoint 渲染器。矩形、直线保持原生可编辑；椭圆、圆角矩形及简单渐变作为独立图片。图表、表格、SmartArt、OLE、未支持的复杂形状或 EMF/WMF 等图片会跳过并在预览中说明；箭头头部、部分文字装饰和特效不保留。字体替换和 PowerPoint/浏览器的文字测量差异可能影响排版，请检查预览。图内已有曲线和坐标轴仍然是图片内容。

需要通过 **start.command** 或 **npm start** 运行本地服务；旧服务需重启后刷新页面。PPTX 在本机读取，不上传到云端，不需安装 PowerPoint。单个 PPTX 上限 100 MB、1–500 页，单页最多 2,000 个转换后对象，图片仍受现有素材限制。`.ppt` 请先在 PowerPoint 中另存为 `.pptx`。

旧的 `scripts/extract_pptx_example.py` 仍是针对已检查的第 4 页布局编写的示例转换工具，不保证适用于其他 PPT；必须显式提供本地 PPTX 路径：

```sh
python3 scripts/extract_pptx_example.py /path/to/source.pptx
```

该脚本会在本地 `examples/` 中写入转换结果；已有结果请先备份。可选的本地素材验证使用现有转换清单和 PPTX 副本，不是运行应用的前提：

```sh
python3 scripts/verify_pptx_example.py
```

默认只输出检查结果，不改写素材或报告。追加 `--check-original` 可读取清单记录的原始文件路径并核对哈希；追加 `--report /path/to/report.json` 可保存报告。私人图稿及转换清单始终保持本地。

图片内部已有的曲线、坐标轴和公式仍是图片内容。编辑器没有持续自动重排的富文本框或组合对象；PPTX 导入时将换行和分组转换为普通对象。旧转换示例中预先烘焙到派生图片的裁剪，只能恢复到该派生图片自身的完整范围；原始 PPT 图片另行保留。

## 开发

应用使用原生 JavaScript 模块，无 npm 依赖。界面使用本地 Figtree 字体和 Magma 配色；字体许可证位于 `assets/fonts/OFL-Figtree.txt`。

在本仓库根目录运行单元测试（需要 Node.js）：

```sh
npm test
python3 -m unittest discover -s tests -p 'test_server.py'
```

启动本地服务器后，打开 <http://127.0.0.1:8766/tests/browser.html>，点击 **Run checks**，验证实际图片解码、SVG 安全检查和 PNG/SVG 导出。所有自动测试均使用合成数据，无须私人论文素材。
