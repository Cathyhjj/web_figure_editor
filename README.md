# Figure Editor

### 交互式 HTML 图表

使用 **Import HTML chart** 选择 `.html` / `.htm`，或把文件拖入画布。文件夹导入也会保留 HTML 素材；点击 **Place** 放置。HTML 原文嵌入 `.figure.json` 项目，保存、重新打开、复制对象和复制 slide 都会保留。

单击图表可以排版；**双击**或在属性中点击 **Interact with chart** 进入画布内的交互视图，使用图表本身的缩放、平移、悬停和图例功能。**Done / Escape** 或取消选中返回排版；最后打开的图表仍继续动画，再次双击会保留当前视角和缩放。调整编辑器缩放、移动对象或编辑其他对象也不会重新加载它，图表按正常对象层级显示。切换 slide、打开另一张交互图表、隐藏/删除图表或替换原 HTML 时才关闭该视图；当前交互状态不会写回原 HTML 或项目。

首次交互会尝试生成 PNG 快照，也可点击 **Save snapshot** 保存当前视图。快照对该素材的所有副本生效，用于缩略图以及 PNG、SVG、PDF、PPTX 和只读 HTML report；这些导出不保留 HTML 交互。没有成功快照时，静态导出会给出提示。Plotly、ECharts、SVG 和 canvas 图表可生成快照；普通 HTML 布局仍可交互，但不会自动截图其 DOM 文本或 CSS 装饰。

建议使用 UTF-8 的单文件图表（内嵌脚本、数据、图片）；Plotly 的 `full_html=True, include_plotlyjs=True` 导出可离线使用。也接受以 `<div>` / `<script>` 开头的 HTML 片段。支持从 `cdn.plot.ly`、`cdn.jsdelivr.net`、`unpkg.com`、`cdnjs.cloudflare.com` 加载库，这类文件需要联网。相对路径脚本、数据文件和其他远程资源不会自动打包，须先内嵌。每个 HTML 文件最多 25 MB。

图表脚本仅在独立的 sandbox iframe 中执行，无法读取编辑器 DOM、项目存储或本地文件。导入素材库、保存及静态导出不会执行原 HTML。

开发验证：`npm test` 包含 HTML 格式识别、模型校验、复制粘贴和导出检查。启动独立测试服务 `python3 server.py --port 18766` 后，运行 `node tests/html-chart-browser.mjs`（需要 Playwright 和 Chrome；可用 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径），验证真实指针悬停、图表缩放、iframe 隔离、保存重开和五种导出。测试使用合成数据与独立浏览器上下文，截图和下载保存到系统临时目录。

本地论文组图编辑器：拖入图片，像在 PPT 中一样移动、缩放、添加文字，再保存项目或导出论文图。应用使用原生 HTML、CSS 和 JavaScript，无须安装 npm 依赖，不使用云端服务或上传素材。

## 启动

**桌面图标（macOS）：**运行一次 `python3 scripts/create_desktop_app.py`，会在桌面创建 **Figure Editor.app**，图标沿用编辑器的三色面板标志。双击即可后台启动服务并打开 Chrome（未安装时使用默认浏览器），无需保留终端窗口。

桌面应用绑定创建时的这个仓库文件夹，直接读取当前文件，包括最新本地 commit 和未提交修改；不复制应用源码，也不自动拉取远程仓库。源码更新后再次双击，会验证运行版本，必要时重启它管理的服务。仍使用 `http://127.0.0.1:8766/`，保留同一浏览器的草稿和布局。日志位于仓库的 `.desktop-runtime/`。如果该端口被旧的手动服务占用，请先在原终端按 `Ctrl + C`；其他程序不会被自动停止。移动仓库后需重新创建桌面图标。

**macOS：双击 [start.command](start.command)**，自动启动本地服务并打开浏览器（需要 Python 3）。已有服务的页面、脚本与本应用一致且支持本地文件定位时会直接复用；若端口被旧的静态服务或其他服务占用，则提示冲突并退出，不会停止其他服务。

也可以在本仓库根目录运行：

```sh
python3 server.py
```

打开 <http://127.0.0.1:8766/>。启动新服务后请保留终端窗口，在终端按 `Ctrl + C` 停止服务。请通过这个本地地址访问，不要直接双击 `index.html`。

推荐使用 Chrome 或 Edge，以便在浏览器支持时关联本地文件。其他浏览器可使用素材副本；具体能力以浏览器提供的权限接口为准。

也可用 `npm start` 启动。升级前若使用 `python3 -m http.server`，请先在旧服务的终端按 `Ctrl + C`，再通过新的启动方式运行并刷新页面，才能使用 **Locate**。

## 基本流程

1. 点击 **Add images / MP4**，或将 PNG、JPG、WebP、SVG、MP4 文件拖入画布。
2. 点击对象后拖动位置，拖动右下角调整大小；图片默认保持比例，按住 `Shift` 拖动可自由缩放。拖动图片左右边的中点只改变宽度，拖动上下边的中点只改变高度；旋转后的图片沿自身方向拉伸，对边保持固定。在 **Object properties** 面板输入精确位置、尺寸、旋转及透明度。
3. 使用 **Text** 添加标注；选中文字后，用顶部 **Font** 选择或输入本机字体名称，调整字号（px），或点击 **A⌃ / A⌄** 放大、缩小。支持多选文字统一修改，锁定对象会跳过，可用 Undo 撤销。双击文字，在 **Object properties** 中编辑内容、字体、字号、颜色和对齐。换行请按 `Enter`。字体需要安装在本机，未安装时浏览器会使用替代字体。
4. 在画布或周围空白处按住鼠标拉框，选中完全框住的图片、文字和形状；向任意方向拖动均可，隐藏和锁定对象会跳过。按住 `Shift` 拉框可追加选择，`Shift + 点击` 可逐个增减选择。拖动任一选中对象即可整体移动，保持相对位置，一次 **Undo** 撤销整组移动。点击空白取消选择，拉框时按 `Esc` 放弃本次框选。也可使用 **Align** 工具；**Distribute horizontally** 将至少三个对象水平等距排列。在 **Layers** 中选择、隐藏或锁定对象。
5. 点击 **Save** 保存包含全部 slides 的 `.figure.json`：新项目首次选择位置，**Open** 打开的项目直接保存回原文件；**Save As…** 另选位置保存副本。点击 **Export** 可将当前 slide 导出为 PNG、SVG 或 PDF，或选择 **PPT** 导出可编辑 PowerPoint，选择 **HTML report** 导出全部 slides 的离线报告。

画布和字号的单位为 CSS px，按 **96 px / inch** 计算物理尺寸。预设为约 85 × 64 mm 单栏、180 × 120 mm 双栏和 120 × 120 mm 方形，整数像素会带来少量尺寸舍入。画布缩放只改变屏幕显示。

点击顶部 **Shapes**，按 **Lines / Rectangles / Basic Shapes / Block Arrows** 分类浏览或搜索，共 92 个可直接插入的形状，另有文本框和 3 个绘图工具。包含 9 种矩形、多边形、饼形、弦形、泪滴、框架、圆环、括号、心形、云、星形、立方体及 31 种块箭头；线条支持直线、肘形、曲线连接线，以及单向/双向箭头。拖动边缘控制点调整宽高；按住 **Shift** 拖动右下角可保持封闭形状的比例。圆仍可拉伸为椭圆。线箭头尖端随线宽调整，旋转字段可改变指向。

**Curve / Freeform**：在画布依次点击控制点，双击或按 **Enter** 完成；Freeform 点击起点可闭合并填充，也可拖动绘制线段。**Scribble**：按住鼠标绘制，松开完成。**Esc** 取消，未完成的绘制不会写入项目。完成后可调整大小、旋转、样式，或撤销/重做。新增预设使用 PPT 几何生成的矢量路径，支持缩放；暂不提供 PowerPoint 的黄色几何调节手柄，连接线也不自动吸附到其他形状。

右键点击画布或 Layers 中的形状、图片，选择 **Format Shape… / Format Picture…**，可打开类似 PowerPoint 的右侧格式面板。面板按 **Fill & Line / Picture / Effects / Size & Properties** 分类，支持折叠分组；关闭按钮恢复常规布局。隐藏或浮动的属性面板会重新停靠，窄窗口下显示为右侧抽屉。右键菜单也提供复制副本、前移、后移、删除和图片裁剪；锁定对象只允许查看格式。选中对象后可用 **Shift + F10** 打开菜单，方向键选择，**Esc** 关闭。

选中形状后，**Format Shape → Fill & Line** 提供独立的 **Fill / Line** 折叠区。Fill 使用 **No fill / Solid fill / Gradient fill** 单选项；Line 提供对应的线条模式、线宽和 **Solid / Dashed / Dotted**。透明度同时提供滑块和百分比输入：**0% 完全不透明，100% 完全透明**；**Object Transparency** 控制整个对象。直线和箭头共用线条样式，虚线箭头的尖端保持实线。旧项目的透明度值继续保留；样式支持撤销、重做、复制、保存和重新打开。

这些形状在 SVG、PDF 和 HTML 报告中保留矢量，在 PPTX 中保留原生可编辑形状；PNG 和复制为图片保留透明度。PPTX 导入支持矢量预设/自定义路径，以及直线、肘形和曲线开放式箭头（连接线弯折位置使用默认中点）。PowerPoint 的原生箭头尖端和虚线间距可能与浏览器略有差异，整体透明度与半透明边框重叠处也可能因渲染器不同而略有差异。

矩形、圆角矩形、椭圆及预设/导入的矢量形状均支持 **Gradient fill**。渐变控件包括预设、**Linear / Radial** 类型、方向、线性渐变角度、2–16 个可增删/拖动的色标，以及所选色标的颜色、位置、透明度、亮度和 **Rotate with shape**。色标支持左右方向键微调，Shift 加快，Home/End 移至两端；双击色带可插入色标。**Line → Gradient line** 使用同一套控件。图片或纹理、图案、幻灯片背景填充不在此面板提供。PPTX 导入/导出保留原生可编辑的线性/径向渐变、亮度和旋转设置；SVG 与 HTML 报告保持矢量，PDF 按所选 DPI 单独渲染渐变对象。浏览器径向渐变尚未经过 PowerPoint 原生像素比对；非圆形路径渐变、区域焦点、不缩放方向及部分斜线投影仍会近似转换，并在 **Import notes** 提示。

形状菜单的数据由 `python3 scripts/build_shape_catalog.py` 从仓库内固定版本的 DrawingML 定义生成，`--check` 可检查生成结果。出处和许可证见 `resources/NOTICE-preset-shapes.txt`；生成器只在副本中修正三个环形箭头定义已知的多余操作数，不更改导入器的严格校验或上游资源。

选中图片后，在 **Format Picture → Effects → Shadow** 勾选开关即可添加阴影。可以选择柔和、右下、下方或硬边预设，也可以用滑块或数值框调整颜色、透明度、大小、模糊、角度和距离。模糊与距离使用与 PPT 相同的 **pt** 单位，角度 `0°` 向右、`90°` 向下。默认效果为黑色、60% 透明、100% 大小、5 pt 模糊、0 pt 距离的居中柔和阴影；透明图片按实际轮廓投影。取消开关或选择 **No shadow** 可移除效果并保留参数。支持撤销、重做，锁定图片时无法调整。

阴影随项目、自动草稿、复制和副本保存；PNG、SVG、PDF、HTML 报告和复制为图片均保留效果，PPT 导出保留为可继续调整的原生阴影。不同渲染器的模糊边缘和半透明图片叠加效果可能略有差异。与其他内容一样，整页导出会裁掉画布外的部分。

选中图片或形状后，在 **Format Picture / Format Shape → Effects → Soft Edges** 设置羽化（柔化边缘）。提供 **1、2.5、5、10、25、50 pt** 预设，滑块和数值框可调 **0–100 pt**；选择 **No soft edges** 或设为 **0** 可移除。文字属性也提供 Soft Edges。羽化沿可见轮廓向内渐隐，保留内部细节和透明度，可与裁剪、边框、阴影组合；锁定对象时无法修改。支持撤销、重做、复制副本、项目保存和重新打开。

PNG、SVG、PDF、HTML 报告及复制为图片均保留羽化；PDF 对带羽化的对象按所选 DPI 单独栅格化。PPTX 导入/导出保留原生可编辑的 **Soft Edges** 半径。浏览器的边缘衰减是近似效果，可能与 PowerPoint 原生渲染略有差异。


PPTX 导入现在保留图片、原生形状、连接线和文字的外阴影，包括颜色、透明度、模糊、距离、大小、对齐和固定方向。形状也可在 **Format Shape → Effects → Shadow** 调整。带整组阴影的组合以可编辑 SVG 保存子图形与内部效果，外层阴影保持原生可调；不会把组阴影重复加到每个孩子。图片自身的实色或渐变描边可在 **Format Picture → Picture → Line** 编辑，并随 PNG/SVG/PDF/PPTX 导出保留。非均匀缩放、倾斜阴影及其他未支持效果会提示近似或省略；缺失的原始图片无法恢复其轮廓和阴影。

## 多页组图与面板

每个项目可包含 **1–100 个 slides**。在左侧 **Slides** 点击缩略图切换页面，用画布上方的 **Slide name** 重命名。

- **New slide**：在当前页后插入空白页，沿用当前画布尺寸和背景。
- **多选**：按住 **⌘ / Ctrl** 点击缩略图可添加或取消选择，**Shift + 点击** 选择连续区间，**⌘ / Ctrl + Shift + 点击** 将区间加入已有选择。在 Slides 面板按 **⌘ / Ctrl + A** 全选；普通点击恢复单选。选中的缩略图高亮，当前画布对应页边框更深。
- **拖动排序**：拖动缩略图到插入提示线的位置；多选后拖动任一选中页会一起移动所有选中 slides，保持组内原顺序，包括不连续的选择。靠近列表边缘会自动滚动，可移动到最前或最后；按 **Esc** 或拖到列表外松开可取消。顺序调整可一次撤销/重做，保留当前页、内容和多选状态；保存项目及多页导出使用调整后的顺序。
- **Duplicate slide**：为所选的一张或多张 slide 生成副本，复制后的对象可独立编辑。
- **Copy / Paste**：复制所有选中 slides，再按原项目顺序一次插入当前页之后；也可用 **⌘ / Ctrl + C、V**。可跨项目粘贴，保留每页名称、尺寸、背景、原图、图层顺序及隐藏/锁定状态。空白页同样支持，共享素材只保留一份；一次撤销/重做处理整批 slides。
- **Delete slide**：删除选中 slides，可用 **Undo** 恢复；至少保留一页，全选时删除按钮禁用。在 Slides 面板按 **⌘ / Ctrl + D** 生成副本，按 **Delete / Backspace** 删除选中页。

**Slides、Assets、Layers、Canvas settings、Object properties** 是五个独立面板。拖动面板标题栏即可将它浮起并移动，也可点击 **Float**；浮动后拖动右下角调整面板大小。停靠时，拖动 Slides 的右边缘、Assets 的左边缘或右侧属性栏的左边缘调整栏宽；拖动 Layers、Canvas settings、Object properties 的底边调整各面板高度，内容较多时可在面板内滚动。窄屏下各栏自动堆叠，可调整面板高度。点击面板标题栏的 **Dock** 可将它放回原来的停靠位置并恢复停靠尺寸，点击 **Reset layout** 可恢复全部面板的默认位置和尺寸。用 Tab 聚焦尺寸手柄后，方向键可调整 10 px，按住 Shift 可微调 1 px；拖动时按 Esc 取消。

顶部 **View → Panels** 可分别勾选显示或隐藏这五个面板；隐藏后释放停靠空间，再次显示时保留原来的位置和大小。**Show all panels** 显示全部面板，**Reset layout** 显示全部面板并恢复默认位置和尺寸。

面板的显示状态、位置、大小和浮动状态会保存在当前浏览器中，刷新或重新打开同一本地地址时恢复；此布局不包含在 `.figure.json` 中。清理浏览器数据会清除保存的布局。面板布局只影响操作界面，不改变画布对象或导出内容。

**Assets** 是整个项目共用的素材库。点击缩略图或素材卡片会优先选中当前页已有的对应对象；如果仅其他页使用了该素材，则跳转到对应页并选中。当前页有多个副本时，保留已选副本，否则优先选中最上层的可见副本。尚未使用的素材会提示通过 **Place** 添加；只有点击 **Place** 才会从素材库向当前页插入新副本，点击或拖动卡片不会插入。**Layers** 只显示当前页的对象。每页的对象位置、文字、样式和画布设置独立；同一素材的 **Link** 或 **Refresh** 更新会反映在所有使用它的页面。

在 **Assets → Add folders** 选择本地文件夹，会递归导入其中及全部子文件夹里的 PNG、JPG、WebP、SVG 图片；也可直接把文件夹拖到 Assets 面板。可重复添加多个文件夹。素材按原目录层级显示，点击文件夹名称可折叠或展开，每层显示包含的图片数；展开后可看缩略图，点击素材选中已有对象，或点击 **Place** 添加到当前页。文件夹导入只添加素材，不会自动铺到画布上。无支持图片的空目录不会显示，其他类型文件会跳过，损坏或超限的图片会显示错误。

目录路径随项目、自动草稿和来源清单保存，同名图片在不同子目录中分别保留。浏览器支持时会关联原图；否则使用内嵌副本。文件夹导入是当次快照，不自动监控之后新增的文件。仍适用单图 25 MB、每次 100 MB / 6400 万解码像素和每项目 500 个素材的限制。

## 保存与本地文件关联

**Save** 保存的 `.figure.json` 包含全部 slides、当前页、对象、样式和一份共享的内嵌素材库，可以搬到另一台电脑重新打开。文件名、原始尺寸、格式、关联状态等来源信息保留在项目中；**Download source list** 下载整个项目的 `.sources.json`，包含跨页素材使用记录。

- **Open recent project**：列出本浏览器最近打开或保存的 10 个项目，点击读取原文件的最新内容；切换前仍会提醒尚未保存的修改。列表刷新后保留，需要时浏览器会重新请求读取权限。不能保留文件访问的条目显示 **Choose file again**，点击后重新选取文件。可逐项移除或 **Clear history**，只清除记录，不删除文件或当前草稿。
- **Save / ⌘或Ctrl+S**：通过 **Open** 选择的已有项目保存回原文件。新项目首次保存时选择文件名和位置，以后的 Save 使用同一文件；修改项目名称不会自动更换文件。
- **Save As… / ⌘或Ctrl+Shift+S**：每次选择新的保存位置，成功后后续 Save 使用新文件。取消或保存失败会保留原保存目标和当前修改。
- **AutoSave**：默认开启，顶部可关闭，设置会保留在当前浏览器中。停止编辑约 1.5 秒后，自动更新已授权写入的项目文件；首次使用先点 **Save** 选择位置。状态显示 **Saving… / Saved to file / Saved locally**；鼠标拖动完成后才写文件，保存期间新增的编辑会继续自动保存。Save As 成功后，AutoSave 也使用新的文件。
- 尚未选择文件或浏览器不支持直接写文件时，只自动保存浏览器草稿，不会反复下载或弹出选址窗口。恢复的文件权限需要重新授权时，显示 **Click Save to allow**；写入失败时显示 **AutoSave failed**，点击 Save 重试。关闭 AutoSave 仍保留本地草稿恢复。
- 支持直接文件访问的浏览器（如 Chrome、Edge）会在需要时请求写入权限。保存目标和草稿一起保留在当前浏览器中，刷新后可继续 Save；如果浏览器不能保留文件访问，Save 按钮提示该关联仅限本次会话。拒绝授权或写入失败时会显示错误，可重试 Save 或选择 Save As。
- 不支持文件选择与写入接口的浏览器仍可 Open，但 Save 和 Save As 只能下载副本，页面会明确提示，无法直接覆盖原文件。升级前已打开的草稿也没有原文件访问权限：首次 Save 需选择原文件位置，之后即可直接保存。

**Open** 兼容旧版单页 v1 项目：打开时将原有画布和对象迁移为第一页，保留素材与来源信息；下次 **Save** 将所选文件更新为多页 v2 格式。若要保留旧版文件，请使用 **Save As…** 保存到另一文件。

从 Finder 拖入图片或文件夹时，会自动保留浏览器提供的原文件关联。支持持久文件句柄时显示 **Local link + copy**；仅提供拖放文件条目的浏览器会保留当前页面会话内的关联，显示 **Session link + copy**，刷新页面后需重新拖入或 Link。素材卡片中的 **Refresh** 重新读取原文件，保留对象排版；**Link** 可重新选择来源。浏览器完全不提供可重复读取的关联时，只能导入副本，导入提示会说明这一点。

持久句柄保存在当前浏览器的本地存储中，不能随 JSON 项目转移；重启浏览器、切换浏览器或撤销权限后，可能需要重新授权。不支持句柄时，**Link** 通过文件选择更新素材副本。

从网页、截图工具或其他应用粘贴图片时，会自动把剪贴板提供的图片原始数据保存成应用目录下 `local-assets/pasted/` 中的独立文件，并在项目中记录相对路径与内容指纹。文件按内容指纹命名，保留 PNG、JPEG、WebP 或 SVG 格式；相同内容复用同一文件，已有文件不会被覆盖。这里保存的是剪贴板中的图片，不会重新下载网页原图。素材卡片显示 **Local file + copy**，项目仍包含可移植的内嵌副本。该目录不纳入 Git；撤销粘贴、删除画布对象或新建项目都不会删除已保存的源文件。

**Locate** 直接在 macOS Finder 中显示并选中素材的源图片，不再弹出选择原图窗口。优先使用本机已记录的位置或内容匹配的仓库路径；外部图片通过 Spotlight 在用户目录中按完整文件名及已有子目录路径查找。只有一个候选时直接显示当前源文件，即使它在导入后被修改、没有旧指纹或只是云端占位文件；不会因此更新项目中的图片副本或排版。多个候选时，在有限读取范围内用内容指纹尝试区分，无法唯一确定则显示提示，不猜测文件，也不弹出文件选择器。未找到时会提示文件可能移动、删除或尚未被 Spotlight 索引。自动识别的位置保存在本地忽略文件 `.local-locations.json` 中，不包含在项目导出中，同一 Link 的 Refresh 不会丢失位置。

粘贴图片使用自动保存到 `local-assets/pasted/` 的源文件；文件缺失时从内嵌副本恢复。明确记录为剪贴板来源但保存失败的图片，Locate 会重试保存。拖入或通过文件选择导入的图片不会被另存为粘贴副本。Locate 不更新 Link 关联；通过 Spotlight 查找外部图片时，不会为了内容校验下载云端占位文件。

自动保存图片与 Locate 需要通过新版 `start.command`、`npm start` 或 `python3 server.py` 启动本地服务；更新后需重启旧服务并刷新页面。普通静态服务器、旧服务或磁盘写入失败时，粘贴仍保留项目内嵌副本，但会明确提示本地源文件未保存；恢复服务后可点击 Locate 重试。

网页不能永久、无权限地读取任意本地路径。关联不可用时仍可使用项目中的副本，编辑和导出不会修改原图。浏览器会自动保存一份包含全部 slides 的当前草稿，但 **New project** 或 **Open** 会替换它；清理浏览器数据可能删除草稿和句柄。浏览器草稿与文件 AutoSave 分开保存；只有显示 **Saved to file** 才表示最新修改已写入项目文件。尚未保存到文件的修改仍会触发离开页面提醒。自动保存不保留历史文件版本，需要保留原版时先关闭 AutoSave，再使用 **Save As…** 另存。

## 导出

点击 **Export**，选择 **File format** 后点击 **Export file**。PNG、SVG 和 PDF 导出当前页，对话框会显示页名；**PPT** 和 **HTML report** 导出项目中的全部 slides，并显示总页数。要保留后续编辑能力，请使用 **Save** 保存项目。

| 格式 | 输出内容 |
| --- | --- |
| PNG | 整张图栅格化；可选 150、300、600 DPI，同时调整输出像素尺寸并写入对应分辨率元数据。 |
| SVG | 编辑器中的文本、形状和导入 SVG 保留为矢量，位图以栅格数据内嵌；字体不嵌入，接收方需要安装相同字体。 |
| PDF | 与画布物理尺寸一致的单页文档。文字转为矢量轮廓（不可搜索或作为文字编辑），实色形状保留矢量；图片保留源像素，SVG 资源、渐变形状和带阴影的图片按所选 150、300、600 DPI 单独栅格化。保留透明度，接收方无须安装相同字体。 |
| PPT (.pptx) | 按项目顺序导出全部 slides；文字和形状为 PowerPoint 原生可编辑对象，图片为可独立移动和缩放的内嵌图片。保留图层顺序、旋转和透明度，不导出隐藏对象。字体不嵌入。 |
| HTML report | 按项目顺序包含全部 slides、页名和目录的单个 `.html` 文件；图像和样式均已内嵌，可离线打开。文本、编辑器形状和导入 SVG 保留为矢量，位图为内嵌栅格，字体不嵌入。报告为只读，不能代替可编辑项目。 |

PNG 的栅格图宽度为 `画布宽度 × DPI / 96`，高度同理。PDF 页面按 `96 CSS px = 1 inch = 72 pt` 保留画布物理尺寸；**PDF effects resolution** 控制 SVG 资源、渐变形状和带阴影或羽化的对象的局部栅格化分辨率，不改变矢量文字、实色形状或其他图片的像素数。提高 DPI 不会补出原始图片中没有的细节；图片属性显示其当前排版下的有效分辨率。过大的阴影图像会被拒绝，请减小图片尺寸或阴影分辨率。

PDF 的文字轮廓通过本地 macOS 服务和系统 CoreText/CoreGraphics 字体框架生成，需要 macOS 与 Swift 命令行工具（Xcode Command Line Tools）。请使用 `start.command`、`npm start` 或 `python3 server.py` 启动，更新后重启旧服务。使用本机安装的字体和系统字体回退，希腊字母、中文等随字体轮廓写入 PDF。普通静态服务器、不支持的系统或文字轮廓服务不可用时，会显示导出错误，不会自动把整页转成位图。只含形状和图片、没有编辑器文字对象的页面无需文字轮廓服务；导出过程不会将项目或字体发送到远程服务。

导入的 SVG 保留为矢量文档，包括路径、文本、分组、线性/径向渐变、透明度、裁剪和静态阴影滤镜。选中后点击 **Edit SVG elements**（或双击图形），可在元素列表中修改路径、填充/描边、文字、变换、渐变色标和阴影的偏移/模糊/颜色。共享渐变或滤镜的修改会影响同一 SVG 内引用它的元素。**Apply** 只修改选中的副本，支持撤销/重做及保存重开；源 SVG 的内部元素在专用编辑窗口中编辑，不会自动拆成主画布上的独立对象。旧项目若保留了原始 SVG，可点击 **Restore editable SVG** 恢复。文本若已转为路径，则仍按路径编辑。

PPT 导出在浏览器中本地完成，无须安装 PowerPoint 或联网。所有页面使用第一页的尺寸；尺寸不同的页面会等比缩放、居中，空白区域为白色。超出 PowerPoint 1–56 英寸范围的第一页会连同内容等比缩放到支持的范围，极端长宽比会提示错误。导出窗口会显示实际尺寸和缩放说明。编辑器中文字按原有换行保留；接收方需安装相同字体，否则排版可能变化。位图内部的曲线、坐标轴和文字仍是图片内容；SVG 以 SVG 源文件和 PNG 兼容预览一同嵌入 PPTX，重新导入本编辑器时优先恢复 SVG。PPTX 中保留为 SVG 图形，不自动拆成 PowerPoint 原生形状；PowerPoint 对复杂 SVG 滤镜的显示取决于其版本。WebP 在导出时转成 PNG。若要回到本编辑器继续编辑，请保留 `.figure.json`。专用 PDF 导出目前会按所选 DPI 渲染导入 SVG（含渐变/阴影）；需要保持这些元素为矢量时，请导出 SVG。

HTML 报告下载后可以直接在浏览器中打开，无须启动编辑器或联网；它不加载外部图像、字体或脚本。用目录跳转到各页，使用浏览器的 **Print** 打印，或在浏览器支持时保存为 PDF。打印版会调整页面排版和缩放，浏览器也可能将部分内容栅格化；需要确定的论文图尺寸或 DPI 时，请使用单页 SVG、PNG 或专用 PDF 导出。继续排版和编辑请保留 `.figure.json`。

## MP4 视频

使用 **Add images / MP4**、拖放或 **Add folders** 导入 MP4。单文件上限 25 MB，每次导入上限 100 MB；视频原始字节与封面一起保存在 `.figure.json`，重新打开不依赖原始文件路径。建议使用 H.264 视频与 AAC 音频；不重新编码，无法在当前浏览器解码或没有视频画面的文件会提示错误。

画布和页面缩略图显示视频第一帧及播放标识。在 Assets 点击 **Preview**，或选中视频后在属性面板点击 **Preview video**，可播放、暂停、拖动进度。视频可移动、缩放、旋转、隐藏、复制和跨页粘贴；暂不提供视频裁切、剪辑或阴影。

选择 **Export → PPT** 后，原始 MP4 与封面嵌入 `.pptx`，无需随 PPT 另带视频文件。在桌面 PowerPoint 的幻灯片放映中点击视频播放。隐藏或未放置的视频不会进入 PPT，重复放置同一视频只嵌入一份原始文件。播放兼容性取决于 PowerPoint 和系统支持的编码。

PNG、SVG、PDF、HTML 报告及复制为图片使用封面帧；这些静态输出不包含可播放视频。

## 图片裁切

选中一张图片，在 **Format Picture → Picture** 点击 **Crop**（已裁切时为 **Edit crop**）。在完整原图预览上拖动四边、四角调整范围，拖动框内移动选区，然后点击 **Apply crop**。**Cancel** 或 `Esc` 放弃本次调整；**Full image** 将预览选区恢复为完整图片，仍需点击 Apply。

点击 **Restore original** 可恢复完整图片；裁切和恢复都支持撤销/重做。原图字节保存在共享素材中，每个图片对象有独立裁切范围；重复裁切、复制对象或页面、保存再打开均保留范围。裁切不会改变源图片的显示比例、旋转或原有位置；恢复时会沿当前图片的缩放和旋转展开。锁定图片需先解锁。

PNG、SVG、PDF、HTML 报告、页面缩略图和跨应用复制均显示裁切后的区域。PPT 导出使用原生可编辑裁切并保留完整嵌入图片。SVG、HTML、PPT 和项目文件仍包含完整源图，裁切只控制可见范围。刷新或重新链接素材后，沿用原有的相对裁切范围。

## 快捷键

`⌘` 用于 macOS，其他系统使用 `Ctrl`。除保存外，下列快捷键在未编辑输入框时生效。

| 操作 | 快捷键 |
| --- | --- |
| 保存项目 | `⌘ / Ctrl + S` |
| 另存项目 | `⌘ / Ctrl + Shift + S` |
| 撤销 / 重做 | `⌘ / Ctrl + Z` / `⌘ / Ctrl + Shift + Z`；也可 `Ctrl + Y` |
| 复制所选 / 粘贴 | `⌘ / Ctrl + C` / `⌘ / Ctrl + V` |
| 复制 / 粘贴所选 slides（先点击缩略图） | `⌘ / Ctrl + C` / `⌘ / Ctrl + V` |
| 全选 slides（焦点在 Slides 面板时） | `⌘ / Ctrl + A` |
| 剪切所选 | `⌘ / Ctrl + X` |
| 直接生成副本 / 全选可见对象 | `⌘ / Ctrl + D` / `⌘ / Ctrl + A` |
| 删除所选 / 取消选择 | `Delete` 或 `Backspace` / `Esc` |
| 移动 1 px / 10 px | 方向键 / `Shift + 方向键` |

先点击画布上的图片、文字或形状，再用 **Cmd+C → Cmd+V** 复制粘贴；支持多选、跨 slide，以及在编辑器项目之间粘贴。副本保留尺寸、样式、图层顺序和图片副本，可独立移动与编辑；每次粘贴略微偏移，支持撤销/重做。复制的对象数据通过系统剪贴板传递，后续复制外部内容会替换它。

使用 **Cmd+X → Cmd+V** 可剪切并移动所选对象，也可粘贴到支持图片的其他应用。剪贴板写入成功后才移除原对象，一次撤销可恢复；写入失败或等待期间原对象发生变化时保留原对象。锁定对象不会被剪切。在文字输入框内，Cmd+X 仍剪切选中的文字。

从截图工具或其他应用复制的 PNG、JPG、WebP、SVG 图片，也可点击画布后直接 **Cmd+V** 导入；来源应用需要向剪贴板提供图片数据，仅有文件路径或网页链接时请使用 **Add local images**。在文字输入框内，复制粘贴仍编辑文本。

浏览器支持系统图片剪贴板时，**Cmd+C** 同时复制透明背景 PNG，随后可在 PowerPoint、微信等支持图片粘贴的应用中按 **Cmd+V**。多选对象会合成为一张图片，保留排版、旋转和透明度；粘回本编辑器仍保持各对象可编辑。PNG 和可编辑对象共同写入成功后，底部显示 **Copied**，再进行粘贴；若写入失败，会显示 **Copy failed**，此时不能认为对象已经复制，可重试或使用 **Export**。不支持系统图片写入的旧浏览器仅复制编辑器对象，并会明确提示。复制图片会按原图分辨率和文字清晰度生成，并受输出像素上限保护；图片内部文字和曲线仍是图片内容。

## 示例与本地素材

**Load example** 优先打开本机可选的 `examples/local-demo.figure.json`。没有该文件时，应用使用代码生成的合成示例；新克隆的仓库可以直接运行，无须论文或外部素材。

本地的 `examples/`、`evidence/`、`chat_history.md`、`.local-backups/` 和用户保存的图稿不纳入 Git。已有的论文示例、PPTX、原始图片、派生图片、来源清单与报告保留在本机。通过 **Open** 可以直接打开保存在其他位置的 `.figure.json`，无须复制到仓库。

### 从 PowerPoint 直接粘贴整页

在 PowerPoint 左侧选择**一张幻灯片缩略图**，按 **⌘C**。回到本机 Figure Editor，点击顶部 **Paste PowerPoint**，会在当前页后插入新 slide；文字、图片、支持的形状分别可编辑。支持撤销、重做、保存和重新打开。形状可调整位置、大小、旋转、填充及线条；混合格式文字可能拆成多个文字对象。**Paste notes** 会列出近似转换及未保留内容。

在画布或 Slides 面板按 **⌘V** 时，浏览器若提供 Office 的 `ppt/slides` 数据会直接转换；若只提供 PNG，则在本机辅助程序就绪且 PNG 字节指纹完全匹配时读取同一份 PowerPoint 数据。若只粘贴成图片，可撤销后用 **Paste PowerPoint**。普通截图仍按图片粘贴，Figure Editor 自身对象和 slide 的剪贴板优先。

系统剪贴板入口需要 macOS、本地服务和 Apple Command Line Tools。服务启动只预编译读取工具，不读取剪贴板；仅用户触发粘贴时读取 allowlist 内的 Office 数据，不上传或修改剪贴板。网页静态托管及其他系统可使用 **Import PPTX**。一次只能复制一页；多页复制会提示使用 PPTX 选页导入。新版本需重启本地服务并刷新编辑器。

支持常见预设形状和有界自定义路径，复杂图表、SmartArt、OLE、部分连接线箭头、阴影和文字特效仍有限制，字体和浏览器文字测量也可能带来细微排版差异。导出 PPTX 时形状路径保持可编辑。

### 从 PowerPoint 导入一页

点击顶部 **Import PPTX**，选择 `.pptx` 文件，然后在 **Choose a slide** 中选择页码。窗口显示转换后的预览、独立对象数量和 **Import notes**；点击 **Insert as new slide**，在当前页之后插入该页，自动切换到新页。一次 Undo 可撤销整页导入，Redo 可恢复；导入不会替换现有页面或改写原 PPTX。

图片与文字分别可编辑，保留画布尺寸、对象位置、尺寸、旋转、图层顺序及常见主题/母版样式。PNG、JPEG、WebP 图片保留源数据，普通裁剪保留完整原图，可用 **Restore original** 恢复。SVG 保留为可编辑矢量文档；PowerPoint 同时存储 SVG 和 PNG 预览时优先读取 SVG，缺失或不受支持时保留 PNG 预览并提示。分组展开为独立对象；文本按本机字体测量换行，混合样式、特殊行距可能拆成多个可编辑文字对象。编辑后的内容随 `.figure.json`、保存/重开及现有导出一起保留。

这是支持常见科研排图元素的导入器，不是完整 PowerPoint 渲染器。矩形、直线和支持的预设/自定义形状保持独立可编辑；椭圆、圆角矩形、直箭头和弯箭头使用矢量路径，线性渐变保留颜色、透明度和方向。图表、表格、SmartArt、OLE、未支持的复杂形状或 EMF/WMF 等图片会跳过并在预览中说明；部分连接线箭头样式、文字装饰和特效不保留。字体替换和 PowerPoint/浏览器的文字测量差异可能影响排版，请检查预览。图内已有曲线和坐标轴仍然是图片内容。

需要通过 **start.command** 或 **npm start** 运行本地服务；旧服务需重启后刷新页面。PPTX 在本机读取，不上传到云端，不需安装 PowerPoint。单个 PPTX 上限 100 MB、1–500 页，单页最多 2,000 个转换后对象，图片仍受现有素材限制。`.ppt` 请先在 PowerPoint 中另存为 `.pptx`。

旧的 `scripts/extract_pptx_example.py` 仍是针对已检查的第 4 页布局编写的示例转换工具，不保证适用于其他 PPT；必须显式提供本地 PPTX 路径：

```sh
python3 scripts/extract_pptx_example.py /path/to/source.pptx
```

该脚本会在本地 `examples/` 中写入转换结果；已有结果请先备份。可选的本地素材验证使用现有转换清单和 PPTX 副本，不是运行应用的前提：

```sh
python3 scripts/verify_pptx_example.py
```

默认只输出检查结果，不改写素材或报告。追加 `--check-original` 可读取清单记录的原始文件路径并核对哈希；追加 `--report /path/to/report.json` 可保存报告。私人图稿及转换清单始终保持本地。

图片内部已有的曲线、坐标轴和公式仍是图片内容。编辑器没有持续自动重排的富文本框或组合对象；PPTX 导入时将换行和分组转换为普通对象。旧转换示例中预先烘焙到派生图片的裁剪，只能恢复到该派生图片自身的完整范围；原始 PPT 图片另行保留。

## 开发

应用使用原生 JavaScript 模块，无 npm 依赖。界面使用本地 Figtree 字体和 Magma 配色；字体许可证位于 `assets/fonts/OFL-Figtree.txt`。

在本仓库根目录运行单元测试（需要 Node.js）：

```sh
npm test
python3 -m unittest discover -s tests -p 'test_server.py'
```

启动本地服务器后，打开 <http://127.0.0.1:8766/tests/browser.html>，点击 **Run checks**，验证实际图片解码、SVG 安全检查和 PNG/SVG 导出。所有自动测试均使用合成数据，无须私人论文素材。
