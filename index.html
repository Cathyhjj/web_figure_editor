PNG: All content is rasterized.

SVG: Editor text, rectangles, and lines remain vector. Images and imported SVGs are rasterized. Fonts are not embedded.

PDF: One page at the canvas size. Text becomes vector outlines (not searchable); rectangles and lines remain vector. Images retain their source pixels, except images with shadows, which are rendered at the selected DPI. Transparency is preserved. Text outlines require the local macOS server; recipients do not need the fonts installed.

PPT (.pptx): All slides with editable text, rectangles, lines, and separate images, plus embedded MP4 videos that play on click in Slide Show. Different canvas sizes are fitted to the first slide. Fonts are not embedded; text may render differently if a font is missing.

HTML report: One offline file containing all slides. Text and shapes remain vector, images are embedded, and fonts are not embedded. The report is read-only.

Videos use static poster frames in PNG, SVG, PDF, and HTML reports. MP4 originals are retained in projects and embedded in PPTX; H.264 video with AAC audio is recommended.

Save an editable project too if you plan to make changes later.
